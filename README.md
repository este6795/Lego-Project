# Lego Project
A website project for generating LEGO build instructions and 3D models from text input, with image input support planned for the future.

## Overview
This project aims to create a web application that can:
- Generate LEGO build instructions from text
- Create a 3D LEGO model based on those instructions
- Potentially accept images as input if time allows

## Current Status
The project is still in an early stage.
- A basic frontend has been created as a placeholder
- A basic backend has been created as a placeholder
- The core algorithm is located in the source code file
- At the moment, the algorithm can generate LEGO cubes

## Features
- Text-to-LEGO build generation
- 3D model output
- Placeholder frontend and backend for development
- Cube-generation algorithm in the source code

## Future Plans
- Improve the backend
- Replace the placeholder frontend with a full interface
- Expand the algorithm beyond LEGO cubes
- Add support for generating build instructions from text
- Add image input support if time allows

## Repository Structure
- source code — contains the current LEGO cube-generation algorithm
- Frontend — basic stand-in user interface
- Backend — basic stand-in server logic

## Roadmap
